主题管理

SYSTEM THEME · 切换为系统级设置，全场屏幕同步生效

如何自建主题插件？
  1. 新建目录 modules/component-theme-<id>/（仅 front/plugin.js + front/view.js，无 index.html、无后端插件）；
  2. 在 web/front.json 追加条目：{ "target": "modules/component-theme-<id>", "enabled": true, "kind": "component", "pages": [ …要生效的页面 id… ] }；
  3. apply 内 ctx.ui.registerComponent("theme:<id>", factory)——factory 渲染本页可见的主题预览卡；
  4. 自带激活逻辑：注入自己的样式表并给 <html> 挂主题类（参考 modules/component-theme-neon/）；读写主题选择用 localStorage["ystage:theme"] 与 GET/PUT /api/theme/active；
  5. 刷新本页即可看到新主题卡；比赛演出（battle-mode）期间请隐藏全部装饰只留背景图。
